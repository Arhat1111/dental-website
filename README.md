# EverSmile dental clinic demo
Open `index.html` in a browser or upload all three files to any static host (GitHub Pages, Cloudflare Pages, Netlify, Vercel).

## Before client launch
- Replace the demo name, contact email, phone, address, dentist names and portraits, metrics, testimonials, and service details with verified clinic information.
- Images are remote Unsplash examples and require internet; obtain appropriate commercial licenses/consent for final photography and consider hosting locally.
- Appointment form prepares an email via the visitor's email app. It does not save submissions or check availability. Change `hello@eversmile.example` in HTML and JavaScript. For reliable bookings, connect a secure backend or a booking service.
- The site is an independently coded design inspired by the linked reference, not a copy of the original proprietary template/assets.
